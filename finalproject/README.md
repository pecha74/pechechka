# Финансовый трекер

**Веб-приложение для учёта личных доходов и расходов** с визуализацией, фильтрацией и расширенной статистикой.

## 🔧 Стек технологий

- **Backend**: Python 3.13, Flask
- **База данных**: PostgreSQL (в Docker-контейнере)
- **Frontend**: Bootstrap 5, Chart.js
- **Дополнительно**: psycopg2, python-dotenv, werkzeug

## 🚀 Функциональные возможности

### Основные
- Регистрация и авторизация пользователей (хеширование паролей)
- Добавление / редактирование / удаление финансовых операций (доходы и расходы)
- Просмотр списка всех операций с сортировкой по дате

### Фильтрация
- По диапазону дат (формат ДД/ММ/ГГГГ)
- По категории (выпадающий список)

### Статистика и графики
- **Простая статистика**: общий баланс, сумма доходов, сумма расходов
- **Круговая диаграмма**: структура расходов по категориям
- **Расширенная статистика**:
  - Линейный график динамики доходов и расходов по месяцам (за 12 месяцев)
  - Столбчатая диаграмма топ-5 категорий расходов
  - Средний расход в день (за последние 30 дней)
  - Общее количество операций

### Безопасность
- Сессии Flask с секретным ключом
- Пароли хранятся в виде хешей (scrypt)
